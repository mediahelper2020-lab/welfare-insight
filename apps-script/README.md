# 교육신청 → 구글 시트 저장 + 문자 알림 (5분 설정)

홈페이지에서 교육신청을 보내면 자동으로

1. **구글 시트**(`복지인사이트 교육신청 내역`)에 한 줄 저장
2. 담당자 휴대폰으로 **문자 알림** (솔라피)
3. 담당자 **이메일 알림**

> 시트는 이미 만들어 두었습니다: https://docs.google.com/spreadsheets/d/1ST-hW1OW_3Zf3UbohubGQKMvuIBEy3iHDkBOYWmWLVc/edit

준비물: 솔라피 **API Key**, **API Secret**, 솔라피에 **등록된 발신번호**, 알림 받을 **휴대폰 번호**

---

## ① 코드 붙여넣고 4칸 채우기

1. 위 시트를 열고 메뉴 **확장 프로그램 → Apps Script**
2. 보이는 코드를 **모두 지우고**, [`Code.gs`](./Code.gs) 내용을 통째로 붙여넣기
3. 맨 위 **[설정]** 칸에 값 입력 → 저장(💾)

```js
SOLAPI_API_KEY: 'NCS로 시작하는 키',
SOLAPI_API_SECRET: '시크릿 값',
SMS_FROM: '07080193355',        // 등록한 발신번호
ADMIN_PHONE: '01012345678',     // 알림 받을 휴대폰
```

## ② 「시작하기」 실행

1. 위쪽 함수 목록에서 **시작하기** 선택 → **▶ 실행**
2. 권한 창이 뜨면: 계정 선택 → **고급** → **(안전하지 않음)으로 이동** → **허용**
   (원장님이 직접 만든 스크립트라 뜨는 일반 안내입니다)
3. 휴대폰으로 **시험 문자**가 오면 성공

## ③ 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 ⚙️ → **웹 앱**
3. 실행: **나** / 액세스 권한: **모든 사용자** → **배포**
4. **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사 → 저에게 보내주시면 홈페이지에 연결합니다.
   (직접 하시려면 `js/data.js`의 `formEndpoint: ""` 따옴표 안에 붙여넣기)

끝! 🎉

### 알아두기
- **문자가 안 올 때**: 시트의 `문자발송` 칸에 `실패: 사유`가 적힙니다. 발신번호 미등록·잔액 부족이 가장 흔한 원인입니다. 실패해도 신청 내용은 시트와 이메일에 남습니다.
- **신청자 접수 안내 문자**는 기본으로 켜져 있습니다(휴대폰 번호일 때만 발송). 끄려면 [설정]의 `NOTIFY_APPLICANT`를 `'false'`로 바꾸세요.
- **새 코드로 바꿀 때**: ① 지금 [설정] 칸 값을 메모장에 복사 → ② 코드 전체를 새 `Code.gs`로 교체 → ③ [설정] 칸 다시 채우고 저장 → ④ 「시작하기」 실행 → ⑤ 배포 → 배포 관리 → ✏️ → 버전 "새 버전" → 배포
- **코드를 고친 뒤에는** 배포 → 배포 관리 → ✏️ → 버전 "새 버전" → 배포 해야 반영됩니다. (URL은 그대로)
- **보안**: API Secret은 이 스크립트에만 넣으세요. 홈페이지 코드에 넣으면 누구나 볼 수 있습니다.
- **개인정보**: 시트 공유는 담당자로만 제한하고, 오래된 신청 행은 정기적으로 삭제하세요.
- 시트 전송이 실패해도 홈페이지가 자동으로 메일(FormSubmit)로 보내므로 신청이 사라지지 않습니다.
