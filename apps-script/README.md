# 교육신청 자동 저장 + 문자 알림 설정

홈페이지에서 교육신청을 보내면 아래 일이 자동으로 일어납니다.

1. **구글 시트**(`복지인사이트 교육신청 내역`)에 한 줄씩 저장
2. 담당자 휴대폰으로 **문자 알림** (솔라피 SOLAPI 사용)
3. (선택) 담당자 **이메일 알림**, 신청자에게 **접수확인 문자**

```
홈페이지 문의폼 ──▶ Google Apps Script(웹앱) ──▶ 구글 시트 저장
                                         └──▶ 솔라피 ──▶ 담당자 휴대폰 문자
```

> 시트는 이미 만들어 두었습니다: **복지인사이트 교육신청 내역** (내 드라이브)
> https://docs.google.com/spreadsheets/d/1ST-hW1OW_3Zf3UbohubGQKMvuIBEy3iHDkBOYWmWLVc/edit

## 1단계. 솔라피 가입 (문자 발송용) — 약 10분

1. https://solapi.com 회원가입
2. **발신번호 등록**: 문자를 보낼 번호(예: 070-8019-3355)를 등록합니다.
   070 번호는 통신서비스 이용증명원 제출이 필요할 수 있습니다. 개인 휴대폰 번호는 본인인증으로 바로 등록됩니다.
3. 소액 충전 (단문 SMS 1건 약 20원, 장문 LMS 약 50원 수준 — 최신 단가는 솔라피에서 확인)
4. **API Key 발급**: 콘솔 → 개발/연동 → API Key 관리 → 새 API Key 만들기
   → `API Key`와 `API Secret`을 메모해 둡니다. (Secret은 다시 볼 수 없으니 꼭 저장)

## 2단계. 시트에 스크립트 붙여넣기 — 약 5분

1. 위 시트를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 통째로 붙여넣고 저장(💾)
4. 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**에서 아래 값을 넣습니다.

| 속성 | 값 예시 | 설명 |
| --- | --- | --- |
| `SOLAPI_API_KEY` | NCS... | 솔라피 API Key |
| `SOLAPI_API_SECRET` | ABC... | 솔라피 API Secret |
| `SMS_FROM` | 07080193355 | 솔라피에 등록한 발신번호 |
| `ADMIN_PHONE` | 01012345678 | 알림 받을 휴대폰. 여러 명이면 `01011112222,01033334444` |
| `ADMIN_EMAIL` | mediahelper2020@gmail.com | (선택) 이메일 알림도 받으려면 입력 |
| `NOTIFY_APPLICANT` | true | (선택) 신청자에게 "접수되었습니다" 문자도 보내려면 `true` |

5. 위쪽 함수 선택에서 **`setup`** 을 고르고 ▶ 실행
   - 처음 실행하면 권한 승인 창이 뜹니다 → 본인 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
     (본인이 만든 스크립트라 뜨는 일반 안내입니다)
   - 시트 머리글 서식, 처리상태 드롭다운이 준비됩니다.
6. 함수 선택에서 **`testSms`** 를 고르고 ▶ 실행 → 담당자 휴대폰으로 시험 문자가 오는지 확인

## 3단계. 웹앱으로 배포 — 약 3분

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설정
   - 설명: `교육신청 수신`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사

## 4단계. 홈페이지에 주소 넣기 — 1분

`js/data.js` 맨 위 `CONTACT` 안의 `formEndpoint`에 복사한 주소를 넣습니다.

```js
formEndpoint: "https://script.google.com/macros/s/여기에_복사한_주소/exec",
```

저장 후 홈페이지에서 시험 신청을 한 번 보내 보세요.
시트에 한 줄이 추가되고, 휴대폰으로 문자가 오면 완료입니다. 🎉

## 운영 팁

- **처리상태**: 시트의 `처리상태` 칸에서 신규 → 연락완료 → 제안발송 → 확정 → 완료 로 바꿔 가며 관리하세요.
- **문자발송** 칸에 `발송완료` / `미설정` / `실패: 사유`가 기록됩니다. 실패해도 신청 내용은 시트에 저장됩니다.
- **스크립트를 고친 뒤**에는 배포 → 배포 관리 → ✏️ → 버전 "새 버전" → 배포 를 해야 반영됩니다. (URL은 그대로)
- **스팸 방지**: 사람 눈에 보이지 않는 칸을 넣어 자동 스팸 프로그램의 신청은 저장하지 않습니다.
- **개인정보**: 시트에는 신청자의 이름·연락처가 저장됩니다. 시트 공유 범위를 담당자로만 제한하고, 보관 기간이 지난 행은 정기적으로 삭제하세요.
- `formEndpoint`를 비워 두면 메일(FormSubmit)로만 전송됩니다. 시트 전송이 실패해도 자동으로 메일로 전달되므로 신청이 사라지지 않습니다.
- 시트 머리글이 바뀌었을 때(예: `희망주제(직접입력)` 열 추가)는 `setup`을 한 번 더 실행하면 1행이 새 머리글로 정리됩니다.
